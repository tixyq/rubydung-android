# RubyDung для Android

**Прототип, из которого вырос Minecraft, теперь у вас в кармане. Сборка 132211, май 2009.**

RubyDung — крошечный Java-эксперимент Маркуса «Нотча» Перссона, написанный до появления Minecraft: куча блоков, камера от первого лица и два действия — *поставить* и *сломать*. Это точный порт самой ранней из сохранившихся сборок, `rd-132211`, который работает на любом устройстве от **Android 1.0 до самых новых версий**.

Никаких меню, экранов загрузки, аккаунтов, рекламы и интернета. Открыл — и уже стоишь в мире.

## Возможности

- **Верность оригиналу.** Те же хитбокс игрока, гравитация, прыжок и трение, та же текстура местности, тот же геймплей: ставишь и ломаешь блоки.
- **Сразу в мир.** Как и в сборке 2009 года, нет ни меню, ни паузы. Мир сохраняется автоматически при выходе.
- **Сенсорное управление, которое удобно.** Крестовина 3×3 слева, взгляд — перетаскиванием, тап ставит блок, удержание ломает.
- **Нормально дружит с железом.** Подключили клавиатуру, мышь или геймпад — сенсорный интерфейс полностью исчезает. Коснулись экрана — он сразу возвращается.
- **И старые телефоны тоже.** Поддерживаются выдвижные клавиатуры и **трекболы**: стрелки и трекбол поворачивают камеру как мышь, Enter ставит блок, Del ломает.
- **Работает везде.** Целевой минимум — API 1 (Android 1.0), при этом устанавливается и на современном Android. Свой EGL 1.0 и OpenGL ES 1.0, без GLSurfaceView и библиотек поддержки.
- **Маленькая и приватная.** Без разрешений, без доступа в сеть, без слежки.

## Управление

### Сенсор (по умолчанию)

| Действие | Жест |
|---|---|
| Движение | Крестовина 3×3 внизу слева (углы — диагонали) |
| Прыжок | Центр крестовины |
| Взгляд | Тянуть пальцем по любому другому месту экрана |
| Поставить блок | Короткий тап |
| Сломать блок | Держать палец неподвижно 0,4 с, дальше ломает, пока держите |

### Клавиатура, трекбол и мышь

Как только вы начинаете пользоваться любым из них, экранные кнопки прячутся и перестают работать. **Одно касание экрана возвращает всё обратно.**

| Действие | Клавиатура | Трекбол | Мышь |
|---|---|---|---|
| Движение | `W` `A` `S` `D` | | |
| Прыжок | `Пробел` | | |
| Взгляд | Стрелки | Покрутить шарик | Двигать мышь |
| Поставить блок | `Enter` | Короткое нажатие | Левая кнопка |
| Сломать блок | `Del` | | Правая кнопка |
| Перекалибровать трекбол | `C` | Долгое нажатие (около 1 с) | |
| Выход | `Back` / `Esc` | | |

Клавиатура и трекбол целятся в центр экрана, мышь — в положение курсора (или в центр, если указатель захвачен, Android 8+).

### Геймпад

Левый стик — движение, правый — взгляд, `A` — прыжок, `X` — поставить, `B` — сломать.

### Калибровка трекбола

У разных телефонов «вправо» на трекболе означает разное: это зависит от положения шарика и от того, как система поворачивает его для альбомной ориентации. При первом движении шарика игра затемняет экран и показывает стрелку вправо: один раз прокатите шарик в эту сторону. Ответ запоминается отдельно для каждого поворота экрана. Любая другая клавиша пропускает калибровку, а `C` или долгое нажатие на шарик запускает её заново. На телефонах без трекбола этого не видно вообще.

## Установка

1. Скачайте `RubyDung-rd-132211.apk` на странице Releases.
2. Разрешите установку из неизвестных источников, если Android спросит.
3. Откройте **RubyDung** и играйте.

Подойдёт любое устройство с OpenGL ES 1.0 (то есть любое).

## Сборка из исходников

Проект собирается без Gradle и Android Studio, одним скриптом.

```sh
./build.sh
```

Скрипт написан для [Termux](https://termux.dev) на Android, но работает на любом Linux с нужными утилитами. Переменная `SDK` должна указывать на папку, где лежит `platforms/android-28/android.jar` (или `android-35`).

Нужны: `javac` (JDK 8+), `d8`, `aapt`, `zipalign`, `apksigner`, `keytool`.

Результат: `out/RubyDung-rd-132211.apk`, подписанный входящим в проект **отладочным** ключом (подписи v1, v2 и v3, `minSdkVersion` 1, `targetSdkVersion` 24). Для публикации используйте собственный ключ.

## Структура проекта

```
src/com/mojang/rubydung/
  RubyDungActivity.java   точка входа
  GameView.java           SurfaceView + цикл на EGL 1.0 / GLES 1.0
  Game.java, Player.java  мир, физика, установка и слом блоков
  Raycaster.java          выбор блока лучом
  Renderer.java           мир, подсветка, сенсорный интерфейс, подсказка калибровки
  TouchControls.java      сенсорный интерфейс в стиле MCPE
  HardwareInput.java      клавиатура, трекбол, мышь, геймпад
  MotionEventCompat.java  обёртки через рефлексию для API новее Android 1.0
  level/                  блоки, сборка мешей чанков, отрисовка мира
assets/                   terrain.png, controls.png
tools/                    десктопные тесты
```

### Тесты

Логика игры и обработка ввода запускаются на обычной десктопной JVM.

```sh
# физика, лучи, мир, меши
javac -d build/testclasses <чистые исходники> tools/LogicTest.java
java -cp build/testclasses LogicTest

# переключение клавиатура / трекбол / мышь / сенсор, калибровка трекбола
# см. tools/InputTest/README.txt
```
